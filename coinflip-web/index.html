      Why it's fair

      • Joining locks both stakes in the same transaction that asks for randomness, so neither player can back out or switch sides.
      • The coin is the random number's last bit, and that number depends on a future block hash: nobody knows it when the flip starts.
      • Verity proves the number on-chain. Each flip is settled once; if no answer arrives in time, both players get their stakes back.
      • There is no house edge and no fee: the winner receives exactly both stakes.
