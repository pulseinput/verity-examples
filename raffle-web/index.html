    Why the draw is fair

    • Ticket sales stop the moment the draw is requested, so nobody can buy in after seeing anything.
    • The random number depends on a future block hash, so nobody knows it when the draw starts.
    • The Verity node must attach a proof, and the coordinator checks it on-chain before the raffle sees the number.
    • Each round is drawn exactly once. If no answer arrives in time, players get refunds, never a re-draw.
